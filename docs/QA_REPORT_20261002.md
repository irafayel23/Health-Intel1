## Defects identified in the initial pass

All three entries below describe the original behavior. They were addressed and rechecked in the follow-up; see the fix verification section.

### 1. Superadmin restart reports success without restarting services

- Location: `assets/js/superadmin/superadmin-health.js`, `restartServices()`.
- Reproduction: Overview → Execute → Force Restart in the isolated environment.
- Actual: “Services Restarted” appears, while the same Node process, start time and authenticated session remain. The handler only shows dialogs and makes no restart API request.
- Expected: the interface must accurately describe the action. Disable/remove the unsupported action, or implement an explicitly authorized, audited restart through a managed service with status verification.
- Impact: misleading operational control; confirmed medium-priority defect.

### 2. Pending and denied Admin accounts appear suspended

- Location: `assets/js/superadmin/superadmin-users.js`, account-table status/action rendering.
- Reproduction: create disposable pending and denied Admin fixtures in the isolated database, then open Admin Access.
- Actual: both are labelled “Suspended” with “Restore”; the renderer treats every non-approved status the same.
- Expected: distinct Pending, Denied and Suspended labels, with actions appropriate to each state. A pending approval must not be presented as restoration of a previously active account.
- Impact: misleading account governance; confirmed medium-priority defect. Backend approval succeeded in the separate API check.

### 3. Weekly report signature block splits across pages

- Location: `server/routes/mho-reports.js`, weekly PDF prepared-by/signature footer.
- Reproduction: download the weekly report containing 15 rows in the isolated browser workflow.
- Actual: all case rows are present, but “Epidemiology Surveillance Officer” spills onto a largely blank second page while the signature line remains on page one.
- Expected: reserve space for the entire signature block and move it together when necessary.
- Impact: report presentation; confirmed medium-priority defect. Smaller weekly exports and the monthly/BHW exports inspected in this pass rendered correctly.
